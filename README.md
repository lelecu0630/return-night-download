# 돌아오지 않은 밤 — Windows 빌드

개발 중인 미스터리 게임의 Windows 빌드 다운로드 페이지입니다.

## 다운로드

[v0.13.23 Windows ZIP](https://github.com/lelecu0630/return-night-download/releases/tag/v0.13.23)을 내려받아 압축을 풀고 `ReturnNight.exe`를 실행하세요. 압축 파일 안의 `ReturnNight_Data` 폴더를 실행 파일과 같은 위치에 두어야 합니다.

이 저장소에는 공개 배포용 게임 파일만 올립니다. 개발 프로젝트는 별도 비공개 저장소에서 관리합니다.
